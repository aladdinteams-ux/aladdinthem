# قالب وردپرس «لاریجانی استون» – سازگار با المنتور و Theme Builder

قالب اختصاصی، راست‌چین و فارسی که از طرح‌های Stitch پروژه «لاریجانی استون» ساخته شده است. همه صفحات طرح (صفحه اصلی در دو نسخه، خدمات، نمونه‌کارها، فروشگاه/کاتالوگ، تک‌محصول، تماس، آرشیو وبلاگ و تک‌مقاله) به صورت ویجت‌های قابل ویرایش المنتور پیاده‌سازی شده‌اند.

## نصب (نسخه ۱.۱)

1. فایل `larijani-stone.zip` را از **نمایش › پوسته‌ها › افزودن › بارگذاری** نصب و **فعال** کنید.
2. **همین لحظه به‌صورت خودکار** ساخته می‌شوند: ۹ برگه طرح (صفحه اصلی، صفحه اصلی کلاسیک، خدمات، نمونه‌کارها، کاتالوگ، فروشگاه محصولات، نمونه محصول، تماس، وبلاگ)، صفحه اصلی و صفحه نوشته‌ها، ۵ منو، قالب‌های تم‌بیلدر، مقاله‌ها و نمونه‌کارهای نمونه. در سایت نو، «سلام دنیا!»، «برگه نمونه» و ابزارک‌های پیش‌فرض هم حذف می‌شوند. تصاویر طرح در پس‌زمینه (WP-Cron) در کتابخانه رسانه کپی می‌شوند.
3. افزونه رایگان **Elementor** را نصب کنید تا برگه‌ها قابل ویرایش بصری شوند. تا قبل از نصب آن هم برگه‌ها با همان طرح نمایش داده می‌شوند. با فعال شدن المنتور، المنتور پرو یا ووکامرس، باقی کارها (قالب‌ها، شرط‌های تم‌بیلدر، محصولات) در اولین ورود به پیشخوان خودکار انجام می‌شود.
4. تنظیمات قالب در منوی **پیشخوان › لاریجانی استون** است (برند و رنگ‌ها، تماس، هدر، فوتر، وبلاگ، فرم‌ها، تم‌بیلدر). همین تنظیمات در «نمایش › سفارشی‌سازی» هم در دسترس و هماهنگ است.
5. برای ساخت دوباره برگه‌ها: **لاریجانی استون › راه‌اندازی و درون‌ریزی**. برای غیرفعال کردن ساخت خودکار: `add_filter( 'ls_auto_setup_on_activation', '__return_false' );`

اسناد تکمیلی: [نقشه اجزای طرح](docs/COMPONENT-MAP.md) · [گزارش سازگاری](docs/COMPATIBILITY.md)

## امکانات تم‌بیلدر

| لوکیشن | Elementor Pro | Elementor رایگان |
|---|---|---|
| هدر / فوتر | شرط نمایش «کل سایت» | سفارشی‌سازی › تم‌بیلدر |
| تک‌نوشته، آرشیو/جستجو | شرط‌های Pro | سفارشی‌سازی › تم‌بیلدر |
| تک‌محصول، فروشگاه (ووکامرس) | شرط‌های Pro | سفارشی‌سازی › تم‌بیلدر |
| ۴۰۴، تک‌پروژه، برگه‌های بدون المنتور | شرط‌های Pro | سفارشی‌سازی › تم‌بیلدر |

- همه لوکیشن‌های اصلی با `register_all_core_location()` برای المنتور پرو ثبت شده‌اند.
- بدون المنتور هم قالب همان طرح را با تمپلیت‌های PHP نمایش می‌دهد.
- فایل JSON همه صفحات و قالب‌ها در پوشه `elementor-templates/` برای درون‌ریزی دستی وجود دارد.

## ۴۵ ویجت اختصاصی (دسته «لاریجانی استون» در پنل المنتور)

هدر، فوتر، مسیر صفحه، هیرو با جستجو، هیرو کلاسیک + فیلتر شناور، کارت‌های آیکون‌دار (۴ سبک)، دسته‌بندی‌ها، محصولات (دستی یا ووکامرس)، درباره ما + آمار، نظرات (شبکه/اسلایدر)، آخرین مقالات، بنر CTA (۵ سبک، با فرم)، هیرو صفحات داخلی، مراحل/نقشه راه، باکس تیره با نمودار دایره‌ای، جدول مقایسه، فرم‌ساز استعلام (آپلود فایل، چندانتخابی، …)، سوالات متداول (با اسکیمای FAQ)، بنر عنوان صفحه، کارت‌های تماس، کارت کارخانه، نقشه (تصویر/iframe/OSM)، هیرو نمونه‌کارها، نمونه‌کارها با فیلتر، نمودار میله‌ای، دکمه شناور، سربرگ فروشگاه، کاتالوگ کامل (جستجو، مرتب‌سازی، فیلتر، صفحه‌بندی)، معرفی محصول (گالری + ماشین‌حساب قیمت عمده و متراژ)، تب‌های محصول، سربرگ وبلاگ، مقاله ویژه، شبکه مقالات (کوئری جاری آرشیو)، ابزارک‌های سایدبار (دانلود، پرطرفدارها، خبرنامه، برچسب‌ها، پشتیبانی، معرفی، فهرست مطالب، ماشین‌حساب) و ویجت‌های تک‌مقاله (سربرگ، محتوا + سایدبار، مرتبط‌ها، دیدگاه‌ها).

هر ویجت تب **استایل** دارد: تغییر رنگ‌های قالب فقط برای همان ویجت، عرض محتوا، فاصله بخش، رنگ پس‌زمینه و تایپوگرافی. امکانات استاندارد المنتور (انیمیشن ورود، واکنش‌گرایی، CSS ID و …) نیز فعال است.

## سایر امکانات

- **رنگ‌های سراسری المنتور**: رنگ‌های «LS – …» در Site Settings به کل قالب متصل‌اند.
- **تگ‌های داینامیک**: تلفن، واتساپ، آدرس، ایمیل، زمان مطالعه، بازدید و … در همه فیلدهای المنتور.
- **آیکون‌های Bootstrap** (بیش از ۲۰۰۰ آیکون) در انتخابگر آیکون المنتور.
- **فرم‌ها**: ارسال AJAX، ذخیره در منوی «درخواست‌ها»، ایمیل به مدیر، ضداسپم (honeypot + محدودیت نرخ)، پیوست فایل.
- **ووکامرس**: قالب فروشگاه و محصول در طرح سایت، تب «اطلاعات لاریجانی» در ویرایش محصول (برچسب‌ها، قیمت عمده خودکار در سبد، ماشین‌حساب متراژ، تضمین‌ها، فرمولاسیون، دیتاشیت)، آیکون برای دسته‌ها.
- **نمونه‌کارها**: پست‌تایپ اختصاصی با دسته‌بندی و فیلدهای کارت.
- **وبلاگ**: شمارش بازدید، زمان مطالعه، مقاله ویژه، تقسیم خودکار محتوا به کارت‌های شماره‌دار، فهرست مطالب خودکار.
- فونت وزیرمتن و آیکون‌ها به صورت محلی (بدون وابستگی به CDN).

## تصاویر

تصاویر طرح از سرورهای گوگل (Stitch) بارگذاری می‌شوند. ابزار راه‌اندازی تلاش می‌کند آن‌ها را در کتابخانه رسانه کپی کند؛ در صورت عدم دسترسی سرور، تصاویر واقعی خود را از تنظیمات هر ویجت جایگزین کنید.

## توسعه

```bash
npm install
npm run build        # ساخت assets/css/tailwind.css و کپی فونت/آیکون‌ها
php build/export-templates.php   # بازسازی فایل‌های JSON المنتور
```
