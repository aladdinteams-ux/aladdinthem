# نقشه اجزای طرح → پیاده‌سازی

| صفحه طرح (ZIP) | برگه ساخته‌شده | اجزای اصلی → پیاده‌سازی |
|---|---|---|
| `_11` صفحه اصلی | `home` (صفحه اصلی) | هیرو + تب جستجو → `ls-hero` · نشان‌های اعتماد → `ls-icon-cards` (badge) · محصولات → `ls-products` (classic) · درباره ما → `ls-about` · نظرات → `ls-testimonials` · مقالات → `ls-posts` (پست‌های واقعی وردپرس) · CTA → `ls-cta` (dark-card) |
| `_1` صفحه اصلی کلاسیک | `home-classic` | هدر روشن → `ls-header` / تنظیم برگه «طرح هدر: کلاسیک» · هیرو + فیلتر شناور → `ls-hero-classic` · دسته‌ها → `ls-categories` · محصولات → `ls-products` (showcase) · چرا ما → `ls-icon-cards` (horizontal) · نظرات → `ls-testimonials` (classic) · کاتالوگ → `ls-cta` (catalog-form، فرم AJAX) |
| `_3` خدمات | `services` | `ls-page-hero`, `ls-icon-cards` (bento), `ls-steps`, `ls-dark-feature`, `ls-comparison`, `ls-lead-form`, `ls-faq` (با اسکیمای FAQ), `ls-cta` (dark-strip) |
| `_4` تماس | `contact` | `ls-page-banner`, `ls-contact-cards`, `ls-plant-card` + `ls-lead-form` (آپلود فایل) در دو ستون المنتور, `ls-map`, `ls-faq`, `ls-cta` (soft-card) |
| `_5` نمونه‌کارها | `portfolio` | `ls-portfolio-hero`, `ls-portfolio` (پست‌تایپ `ls_project` + فیلتر), `ls-performance`, `ls-lead-form`, `ls-floating-cta` |
| `_6` / `_8` کاتالوگ با سایدبار | `shop` (یا فروشگاه ووکامرس) | `ls-shop-hero` (card), `ls-catalog` (sidebar: جستجو، مرتب‌سازی، فیلتر، محدوده قیمت), `ls-icon-cards`, `ls-cta` (dark-form) |
| `_2` فروشگاه تمام‌عرض | `products` | `ls-shop-hero` (bar), `ls-catalog` (store، کارت `store`), `ls-cta` (consult-band), `ls-icon-cards` (guide) |
| `_7` تک‌محصول | `product-sample` / قالب «تک‌محصول» | `ls-product-detail` (گالری، ماشین‌حساب قیمت عمده و متراژ، افزودن به سبد ووکامرس), `ls-product-tabs`, `ls-products` (compact), `ls-cta` |
| `_9` آرشیو وبلاگ | `blog` + قالب «آرشیو» | `ls-blog-hero`, `ls-featured-post`, `ls-posts-grid` + ابزارک‌های سایدبار (`ls-sidebar-*`) |
| `_10` تک‌مقاله | قالب «تک‌نوشته» | `ls-post-hero` (کارت‌های شاخص از فیلد مقاله), `ls-post-content` (کارت‌های شماره‌دار، فهرست مطالب، ماشین‌حساب رزین), `ls-related-posts`, دیدگاه‌ها (`comments.php` با طرح «پاسخ تایید شده»), `ls-cta` |
| همه | قالب‌های هدر/فوتر | `ls-header` (تیره/روشن، منوی کشویی، منوی موبایل، جستجو), `ls-footer` |

**بومی وردپرس:** منوها، ابزارک‌ها، دیدگاه‌ها، پست‌تایپ‌های `ls_project` و `ls_lead`، صفحه‌بندی، جستجو، برگه‌های ۴۰۴.
**بومی المنتور:** بخش/ستون‌ها، رنگ‌های سراسری (Site Settings)، تگ‌های داینامیک، کتابخانه آیکون Bootstrap، لوکیشن‌های Theme Builder.
**ویجت سفارشی:** ۴۵ ویجت `ls-*` (دسته «لاریجانی استون» در پنل المنتور) – طرح‌هایی که ویجت‌های بومی المنتور نمی‌توانند دقیقاً بسازند.
