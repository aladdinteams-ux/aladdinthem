# نقشه اتصال المان‌ها به ویجت‌های المنتور – Larijani Stone 1.3.0

از نسخه ۱.۳ چیدمان همه صفحاتی که با نصب قالب ساخته می‌شوند با **کانتینر (Flexbox / Grid) المنتور** ساخته می‌شود و بخش‌های ثابت طرح از **ویجت‌های خود المنتور** تشکیل شده‌اند. هر متن، آیکون، لینک، تصویر، رنگ، فونت، فاصله و تعداد ستون در پنل خود المنتور (تب‌های محتوا / استایل / پیشرفته) ویرایش می‌شود.

ویجت‌های اختصاصی قالب فقط برای بخش‌هایی مانده‌اند که المنتور (رایگان یا پرو) ویجت معادل ندارد یا داده‌محور/تعاملی هستند؛ آن‌ها هم کامل در المنتور قابل ویرایش‌اند (کنترل‌های محتوا + تب استایل).

## بخش‌هایی که با ویجت‌های بومی المنتور ساخته می‌شوند

| بخش طرح | صفحات | ویجت‌های المنتور |
|---|---|---|
| عنوان بخش‌ها (متن کوچک، عنوان، توضیح، لینک) | همه | Heading، Text Editor، Button |
| نشان‌های اعتماد / کارت‌های مزایا (۵ سبک: فشرده، افقی، ستونی، بنتو با برچسب، کادر راهنما) | اصلی، اصلی کلاسیک، خدمات، کاتالوگ، فروشگاه، قالب آرشیو محصول | Container (Grid) + Icon + Heading + Text Editor + Icon List (برچسب‌ها) + Button |
| درباره ما + آمار | اصلی | Heading، Text Editor، Button، Image، Container (Grid) آمار |
| نظرات مشتریان (حالت شبکه‌ای) | اصلی | Container + Heading (نقل‌قول، نام، سمت، حرف اول نام) + Text Editor + Star Rating + Image (آواتار در صورت وجود) |
| بنر دعوت به اقدام (کارت تیره، نوار تیره، کارت ملایم، نوار مشاوره با شماره‌ها) | اصلی، خدمات، تماس، فروشگاه، نمونه محصول، قالب تک‌نوشته/آرشیو/محصول | Heading، Text Editor، Button، Icon، Icon List، Container با لینک (دکمه دوخطی) |
| مراحل راه‌اندازی + کارت‌های تصویری | خدمات | Container (Grid) + Heading (شماره) + Icon + Heading + Text Editor + Image |
| بنر عنوان صفحه با شاخص زمان پاسخ | تماس | Heading (H1)، Text Editor، Icon، Progress Bar |
| کارت‌های تماس (شماره، دکمه تماس/واتس‌اپ، ساعات کاری) | تماس | Icon، Heading، Text Editor، Button، Container (Grid) |

## بخش‌هایی که ویجت اختصاصی قالب (قابل ویرایش در المنتور) مانده‌اند و دلیل آن

| ویجت | دلیل |
|---|---|
| هدر / فوتر | منوی موبایل کشویی با تله فوکوس و دسترس‌پذیری، جستجوی پاپ‌آپ، هدر چسبان؛ لینک‌ها از **نمایش › فهرست‌ها** می‌آیند (با نصب قالب ساخته و به برگه‌ها متصل می‌شوند). با المنتور پرو می‌توانید هدر/فوتر خودتان را با Nav Menu بسازید؛ قالب لوکیشن‌ها را ثبت کرده است. |
| هیروی صفحه اصلی (با جستجوی سه‌فیلدی) و هیروی کلاسیک (فیلتر شناور) | فرم جستجوی محصول با تب‌ها و پارامترهای فیلتر |
| محصولات، کاتالوگ کامل، معرفی محصول، تب‌های محصول، سربرگ فروشگاه | داده‌محور (ووکامرس یا کارت‌های دستی)، فیلتر/مرتب‌سازی/محدوده قیمت، ماشین‌حساب قیمت عمده و متراژ — المنتور رایگان ویجت محصول ندارد |
| مقالات، مقاله ویژه، شبکه مقالات، ویجت‌های تک‌مقاله و سایدبار | کوئری نوشته‌ها، زمان مطالعه، بازدید، فهرست مطالب خودکار — بدون المنتور پرو ویجت معادل نیست |
| فرم استعلام و بنرهای دارای فرم | ذخیره درخواست‌ها در پیشخوان، آپلود فایل، ضداسپم — فرم المنتور فقط در نسخه پرو است |
| سوالات متداول | اسکیمای FAQPage با مالکیت سئو (در حضور افزونه سئو خاموش می‌شود) |
| نظرات (حالت اسلایدر)، نمونه‌کارها با فیلتر، نمودارها، جدول مقایسه، دکمه شناور، نقشه، کارت کارخانه | تعاملی یا طرح ویژه بدون معادل بومی |

## نکات ویرایش

- کلاس‌های ظاهری طرح در **پیشرفته › کلاس‌های CSS** هر ویجت/کانتینر قرار دارند؛ هر مقداری که در **تب استایل** بدهید (رنگ، تایپوگرافی، پس‌زمینه، حاشیه، سایه، فاصله) بر آن‌ها اولویت دارد (در المنتور ۴.۰ آزموده شد).
- فاصله عمودی ویجت‌ها در **پیشرفته › حاشیه (Margin)** و فاصله بین المان‌ها در **Gap** کانتینر تنظیم شده است.
- برای بازسازی برگه‌هایی که با نسخه‌های قبل ساخته شده‌اند: **لاریجانی استون › راه‌اندازی و درون‌ریزی › «بازسازی چیدمان»** (نسخه قبلی در `_ls_elementor_data_backup` نگه داشته می‌شود).
- برای بازگشت به چیدمان قدیمی با ویجت‌های اختصاصی: `add_filter( 'ls_native_layouts', '__return_false' );`
