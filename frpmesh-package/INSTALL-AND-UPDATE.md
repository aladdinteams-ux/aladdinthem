# راهنمای نصب و به‌روزرسانی FRP Mesh 3.9.1

## پیش‌نیازها
وردپرس ۶٫۳+ (آزمون‌شده روی ۶٫۹)، PHP ۷٫۴+ (آزمون‌شده روی ۸٫۳)، Elementor رایگان (برای ویرایش بصری؛ بدون آن طراحی اصلی نمایش داده می‌شود). Elementor Pro و ووکامرس اختیاری‌اند.

## نصب تازه
1. از فایل‌ها و دیتابیس بکاپ بگیرید.
2. Elementor رایگان را نصب و فعال کنید.
3. «افزونه‌ها ← افزودن ← بارگذاری» : `frpmesh-editor.zip` را نصب و فعال کنید.
4. «نمایش ← پوسته‌ها ← بارگذاری» : `frpmesh-hybrid.zip` را نصب و فعال کنید.
5. در نخستین ورود مدیر، صفحات خانه/درباره/خدمات/تماس/وبلاگ و الگوها ساخته می‌شوند (صفحات و منوی موجود دست‌نخورده می‌مانند). وضعیت را در «طراحی FRP ← راه‌اندازی Elementor» ببینید.
6. فونت (Vazirmatn) و ویدئوی صفحهٔ اصلی در پکیج نیست؛ از «طراحی FRP ← تنظیمات طراحی» بارگذاری کنید، وگرنه ویدئو پیش‌فرض ۴۰۴ می‌دهد.

## به‌روزرسانی از 3.x
1. بکاپ کامل. 2. افزونه را با `frpmesh-editor.zip` جایگزین کنید (گزینهٔ «جایگزینی نسخهٔ فعلی»)، سپس قالب را با `frpmesh-hybrid.zip`. هیچ‌یک را حذف نکنید؛ حذف قالب/افزونه تنظیمات را پاک نمی‌کند ولی بهتر است جایگزینی انجام شود.
3. تنظیمات، صفحات، متن بخش‌ها و منو بدون تغییر می‌مانند. اسکن ویجت‌های قدیمی خودکار در پس‌زمینه (WP-Cron) انجام می‌شود؛ پیشرفت آن در «راه‌اندازی Elementor» دیده می‌شود. پاک‌کردن کش افزونهٔ کش و کش المنتور (Tools ← Regenerate CSS) توصیه می‌شود.
4. اگر DISABLE_WP_CRON فعال است، سرور باید cron سیستمی (wp-cron.php) را اجرا کند یا یک بار به‌صورت دستی «اجرای مرحله بعد» را بزنید.

## حذف
حذف افزونه فقط وضعیت فنی (اسکن/قفل) را پاک می‌کند؛ صفحات، الگوها و تنظیمات شما می‌مانند.
