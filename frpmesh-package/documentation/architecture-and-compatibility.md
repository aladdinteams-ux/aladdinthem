# معماری و سازگاری نسخه ۳

پوسته مستقل frpmesh-hybrid همراه افزونه اتصال frpmesh-editor: معماری Hybrid با Elementor رایگان. پوسته HTML/CSS/JS منبع را نگه می‌دارد و داده صفحه از ابزارهای اصلی Elementor ساخته می‌شود. فقط فیلدهای تعاملی و داده وردپرس دو نوع ابزار اختصاصی دارند. نیازی به Hello Elementor نیست.

## داده و ویرایش
متن، تصاویر، آیکون‌ها، دکمه‌ها و ساختار بخش‌ها با ابزارهای بومی قابل ویرایش‌اند. منو، لوگو، مقالات، دسته‌ها و صفحه‌بندی از API وردپرس خوانده می‌شوند. شناسه‌ها و کلاس‌های رفتاری باید برای تعاملات JS باقی بمانند. همه تنظیمات پیشرفته ابزارهای Elementor پوشش یا آزمون کامل ندارند؛ محدودیت‌های README را بخوانید.

## وابستگی‌ها
الزامی: WordPress، Elementor رایگان، پوسته و افزونه همراه. آزمون واقعی: WordPress 6.8.9، PHP 8.3.33، Elementor 4.2.4. حداقل اعلام‌شده WordPress 6.3 و PHP 7.4 در اجرا آزموده نشده است.
اختیاری: Elementor Pro، افزونه SEO، کش و فرم. Pro و ماتریس افزونه‌های دیگر در این محیط نصب و آزموده نشده‌اند. فروشگاه در منبع نبود و اتصال WooCommerce پیاده نشده است.

## SEO، عملکرد و امنیت
حفظ ساختار معنایی و لینک‌های پویا؛ پشتیبانی title-tag و تصویر شاخص؛ عدم ایجاد canonical/schema رقیب افزونه SEO. دارایی‌ها با enqueue و نسخه فایل، بارگذاری وابسته به صفحه و پاک‌سازی چرخه JS مدیریت می‌شوند. تصویر قهرمان بی‌دلیل lazy-load نشده است. امتیاز Lighthouse یا اعداد LCP/INP/CLS اندازه‌گیری نشده‌اند.
خروجی پویا escape و متن محدود با KSES پالایش می‌شود؛ تنظیمات و راه‌انداز nonce و capability دارند. کد آزمون، حساب آزمایشی و مسیرهای QA در ZIP نصب نیستند. Core، قالب والد و افزونه ثالث تغییر نکرده‌اند.

## به‌روزرسانی
APIهای عمومی WordPress، قالب مستقل و دارایی‌های محلی کم‌ریسک‌ترند. رفتار DOM، کش، کنترل‌ها و hookهای render/preview Elementor و سازگاری محتوای قدیمی نیازمند آزمون پس از آپدیت عمده‌اند. تضمین امنیت مطلق، تطابق پیکسلی کامل یا سازگاری همه نسخه‌های آینده داده نمی‌شود. پیش از ارتقا بکاپ کامل بگیرید و روی staging بررسی کنید.
