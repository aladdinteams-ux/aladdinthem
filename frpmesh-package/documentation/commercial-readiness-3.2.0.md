# ماتریس قابلیت و آماده‌سازی فروش FRP Mesh 3.2.0

| مورد | پیاده‌سازی | محدودیت / آزمون لازم |
| --- | --- | --- |
| Theme Builder | ثبت چهار محل و fallback؛ Pro فعال با شرط معتبر اولویت دارد | Elementor Pro واقعی در این دور نصب و آزموده نشد |
| Canvas | قالب مستقل بدون Header/Footer همراه توابع استاندارد WP؛ حالت Canvas بومی Elementor نیز قابل انتخاب است | پیش‌نمایش editor و سایت مقصد نیازمند تأیید |
| Full Width | قالب مستقل با محتوای تمام عرض و Header/Footer؛ حالت Elementor Full Width نیز قابل انتخاب است | تداخل CSS افزونه‌های سایت مقصد سنجیده نشده |
| Container | اسناد نمونه با کانتینرهای واقعی؛ شاخه‌ها در editor مستقل | همه حالت‌های responsive و Advanced پوشش کامل ندارند |
| Global Colors | اتصال اختیاری به چهار متغیر استاندارد Elementor بدون تغییر خودکار کیت موجود | رنگ‌های اختصاصی متعدد منبع هنوز ثابت؛ تنظیم کیت به عهده طراح |
| Global Fonts | اتصال اختیاری Primary/Text و فونت FRP موجود در تنظیمات | فایل فونت اصلی منبع موجود نبود؛ فونت خریداری یا مجوزدار لازم است |
| Custom Widgets | دو استثنای اختصاصی در دسته FRP Mesh؛ سایر محتوا از ابزار اصلی | ورودی‌های JS به کلاس و ID اصلی وابسته‌اند |
| فروش | ZIP نصب، README و اسناد ویرایش نمونه موجود | مجوز بازفروش دارایی‌های ثالث و آزمون نصب پاک/Pro/ماتریس پلاگین‌ها تأیید نشده |

ساختار صفحه‌ها و الگوها بدون تغییر داده ذخیره‌شده قبلی نگه داشته شده است. archive/search/home مسیر Theme Builder archive و page/single/404 مسیر single را دارند. هدر و فوتر از قبل به محل استاندارد متصل بودند. ناحیه Canvas فقط محتوای برگه و hookهای حیاتی WordPress را دارد. اتصال Global Styles از تنظیمات FRP ویرایش می‌شود و به متغیرهای تولیدی Elementor متکی است؛ اگر قالب kit آن‌ها را تولید نکند، مقادیر پشتیبان CSS استفاده می‌شوند.

## دروازه‌های انتشار تجاری
1. بررسی حقوق انتشار تصویر، لوگو، SVG، JS، متن نمونه و فونت و نگهداری گواهی.
2. نصب پاک روی نسخه‌های مشخص WordPress/PHP/Elementor و Pro با ثبت video/screenshots؛ آزمون تغییر و ذخیره همه صفحات، ۴ محل Theme Builder و هر دو Page Layout.
3. نصب روی سایت دارای داده قبلی، آزمون مسیر ارتقا و بازگردانی، رفع هشدارهای PHP و درخواست‌های 500/404.
4. سنجش بصری دسکتاپ/تبلت/موبایل در مرورگرهای هدف و اجرای واقعی Core Web Vitals.
5. بسته راهنمای پشتیبانی، changelog و خط‌مشی به‌روزرسانی برای مشتریان.

در این محیط PHP runtime و WordPress اجرایی در دسترس نبود؛ برای این نسخه فقط JSON، ساختار فایل، CRC ZIP و بازبینی ایستا قابل انجام بود. آزمایش ویرایش زنده ثبت‌شده داخل validation متعلق به نسخه پایه ۳.۰.۰ است و به معنی آزمون ویژگی‌های جدید ۳.۲.۰ نیست.
