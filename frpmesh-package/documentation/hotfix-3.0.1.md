# اصلاح ۳.۰.۱ — تابع افزونه همراه در دسترس نبود

گزارش سایت کاربر در 18-Sep-2026 نشان داد functions.php پوسته در نمایش صفحات home و contact تابع frpme_native_document را صدا می‌زند، اما تابع تعریف نشده است. این گزارش نبود API را ثابت می‌کند؛ علت نصب ناقص یا باقی‌ماندن نسخه قبلی بدون دسترسی به فایل‌های نصب کاربر قطعی نیست.

دو محل فراخوانی با helper بررسی function_exists محافظت شدند. افزونه قدیمی مسیر نمایش قبلی را حفظ می‌کند و پیام ارتقا در مدیریت نشان داده می‌شود. پوسته و افزونه همراه نسخه 3.0.1 باید با هم نصب شوند؛ برای این اصلاح، ساخت مجدد صفحات یا تغییر محتوای ذخیره‌شده لازم نیست.

آزمون رگرسیون PHP با stub افزونه قدیمی فاقد API: نمایش برگه المنتوری و الگوی ذخیره‌شده بدون fatal و بدون حذف محتوا گذشت. با stub افزونه نسخه ۳ دارای API، مسیر محتوای بومی بدون wrapper اضافی حفظ شد. syntax فایل‌های تغییرکرده و CRC ZIP بررسی شدند. این آزمون محدود است؛ رفع خطا روی Laragon کاربر هنوز تایید عملی نشده است. گزارش آزمون‌های کامل نسخه 3.0.0 نیز در بسته حفظ شده و به معنای اجرای مجدد همه آن‌ها برای hotfix نیست.
