# اصلاح ۳.۰.۲ — ناحیه محتوا در پیش‌نمایش برگه خالی

در مسیر frpmt_page، برگه‌ای که هنوز is_built_with_elementor نبود به نمایش مرجع هدایت می‌شد و the_content فراخوانی نمی‌شد. اکنون preview->is_preview_mode نیز کنترل می‌شود و پیش‌نمایش از the_content همان برگه استفاده می‌کند. single.php نیز برای پیش‌نمایش و محتوای المنتوری، محتوای خود سند را نمایش می‌دهد. ظاهر پیش‌فرض برگه‌های عادی فاقد داده المنتوری تغییر نکرده است.

آزمون PHP با stub برگه فاقد داده قبلی و preview فعال موفق بود: مسیر the_content فراخوانی شد. آزمون‌های رگرسیون نبود API نسخه قدیمی و وجود API نسخه ۳ و lint فایل‌های تغییرکرده گذشتند. این‌ها آزمون‌های مسیر PHP هستند؛ اجرای ویرایشگر واقعی روی Laragon کاربر هنوز تایید نشده و آزمون‌های کامل نسخه پایه دوباره اجرا نشده‌اند.

لاگ جدید پیام Server shutdown in progress دارد؛ دیتابیس در زمان درخواست در حال توقف بوده است. هشدار editor_post_id از ماژول تاریخچه Elementor است؛ این پیام به‌تنهایی دلیل شکست پیش‌نمایش را ثابت نمی‌کند. افزونه ثالث یا Core برای رفع آن‌ها تغییر نکرده‌اند.

برای نصب، پوسته و افزونه را با فایل‌های همراه نسخه 3.0.2 جایگزین کنید. صفحه را از فهرست برگه‌ها باز کنید. برگه‌ای که در تنظیمات خواندن، برگه نوشته‌ها تعیین شده با منطق آرشیو نمایش داده می‌شود؛ طراحی آرشیو را از الگوی وبلاگ راه‌انداز ویرایش کنید. برای اصلاح خطا، محتوای برگه‌های ساخته‌شده را دوباره جایگزین نکنید.
