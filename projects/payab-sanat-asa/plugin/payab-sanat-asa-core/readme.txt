Companion plugin of the Payab Sanat Asa theme: built-in three-language layer, reversible import, SEO tags, free-Elementor widget, WooCommerce catalog mode.

== Description ==
* Languages fa (site root), en (/en/), ar (/ar/) with translation groups, language switcher targets and hreflang.
* Reversible import of 66 pages and 9 products, with a journal and Undo (moves to Trash).
* "Payab Element" Elementor widget (tag, class, link, text, image + alt, inner markup) and an attribute control on containers. Free Elementor only.
* Settings > Aladdin Payab: texts of header/footer/mega menu for each language, catalog mode, SEO switch, optional Elementor templates for header/footer.
* Never changes an existing site on activation. Uninstall removes settings only; pages and products stay.

== Installation ==
Install with the Payab Sanat Asa theme. Elementor (free) and WooCommerce are optional.
