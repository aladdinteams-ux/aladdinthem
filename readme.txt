Right-to-left (Persian) business theme for Elementor (free version is enough) with an optional WooCommerce shop.

== Description ==

Designed and developed by Aladdin Theme (علاءالدین تم).

Larijani Stone is a Persian (RTL) theme for industrial and building-material companies.
It ships native Elementor layouts and 40+ Elementor widgets, a built-in theme builder for the
free Elementor (Elementor Pro is optional), configurable colours and typography, WooCommerce
templates, and a setup wizard with a reversible demo import.

Portfolio projects, customer inquiries and secure forms (private file uploads, spam protection)
are provided by the companion plugin "Larijani Stone Core", included in the theme package
(bundled/larijani-stone-core.zip) and installed from Larijani Stone > Setup.

Full Persian guides: docs/INSTALL-FA.md (installation, demo import, settings, requirements).

== Installation ==

1. Appearance > Themes > Add New > Upload Theme, choose larijani-stone.zip, Install, Activate.
2. Open "Larijani Stone > Setup" (راه‌اندازی و درون‌ریزی):
   check the server requirements, install the companion plugin and Elementor with the buttons,
   then choose what to import. Nothing is installed or imported without your click on sites
   that already have content.
3. Optional: install the child theme (larijani-stone-child.zip) for your own code changes.

== Frequently Asked Questions ==

= Is Elementor Pro required? =
No. Header, footer, archive, product and 404 templates work with free Elementor through the
theme's built-in theme builder. With a licensed Elementor Pro, its Theme Builder is used instead.

= Will the demo import change my existing content? =
No. It only creates new items, fills empty menu locations and empty theme-builder slots, and
asks before replacing the front page. Every run is journaled and can be undone.
